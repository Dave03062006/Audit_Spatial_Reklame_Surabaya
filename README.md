# Audit Spasial Reklame Rokok dan Alkohol Dekat Sekolah Surabaya

Aplikasi desktop (Python + Pygame) untuk memeriksa reklame rokok, rokok elektronik,
dan minuman beralkohol di Surabaya terhadap PP 28/2024 Ps. 449 dan Perda Surabaya 5/2019.

Petunjuk lengkap ada di bagian bawah setelah aplikasi selesai.
